# 义警检查机制

`义警` 会在 **第八天** 到来，不会检查主角

在 **第十天** 再来时，则会第一次检查

:::warning
在第一次检查中检查过的部位无法在第二次检查中重复检查！
:::

在 **第十二天** 则会第二次检查

在两次检查中若被他判为伪人，则会直接对枪进入插曲结局

## 主角自身特征

::::warning
电视播出的伪人特征均不属实，然而义警却盲目听信从而滥杀无辜，
所以在检查时要确保自身特征不符合电视播出的伪人特征才可以通过检查

:::note
通常建议让义警检查以下内容:

- 不挖洞或挖洞后已经洗手：检查双手
- 没喝过饮料/咖啡：检查眼睛
- 已经自查过腋下：检查腋下
- 已经确定家里无伪人：检查照片

:::
::::

:::tip[牙齿]
牙齿本来很白，会被认定为伪人，可以通过吸烟来使得牙黄，然后才可检查牙齿
:::

:::tip[双手]
双手在不挖洞的情况下不会有泥土，可以直接检查

挖洞后可以通过自查来清洗双手
:::

:::tip[眼睛]
眼睛会在喝饮料或咖啡后变红，需要等几天才可消红
:::

:::tip[腋下]
腋下会每隔几天或喝茶后长真菌，可以通过自查来清洗腋下
:::

:::tip[拍照]
当家里有伪人时，照片会有异常，确保家里住客均为人类即可通过检查
:::

:::tip[耳朵]
由于义警自发当义警过早，并不知道该检查点，检查耳朵会不通过
:::
