# 道具机制

## 快递

订快递需要在 **第二天** 通过观看电视取得电话号码后才可电话订购，每三天可以订一次，当晚 `快递员` 会送达快递

:::note
若没有及时观看电视，则需要多等几天再看电视才可以获取电话号码
:::

## 道具

:::note
除啤酒是**无限供应**之外，其他道具均为**有限使用**

部分道具家里自带，部分道具可以通过快递订购，部分住客在进门时贿赂或个人剧情中也会给予道具
:::

:::tip[波伯黑啤]
由邻居带来的无限啤酒，喝后清空体力
:::

:::tip[劲能佳]
可以通过快递订购（一次 `两罐`）

喝后增加 **`一格` 体力**

会使 `三天` 内**眼睛变红并快速移动**
:::

:::tip[咖啡]
可以通过快递订购

喝后在 `四天` 内增加 **`一格` 体力槽**

会使 `四天` 内**眼睛变红并快速移动**
:::

:::tip[猫粮]
可以通过快递订购（一次 `两个`）

用于**喂猫**
:::

:::tip[香烟]
可以通过快递订购

恢复**所有体力**，但 `下一天` **少 `一格` 体力**

会使 `当天` **牙齿变黄**
:::

::::tip[康普茶]
家里自带 `一罐`，可以通过快递订购

用于**存档**

会使**腋下长真菌**

:::note
使用游戏菜单的保存功能同样可以存档
:::
::::
