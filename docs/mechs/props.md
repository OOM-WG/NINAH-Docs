# 道具机制

## 外卖

订外卖需要在 **第二天** 通过观看电视取得电话号码后才可电话订购，每三天可以订一次，当晚快递员会送达快递

:::note
若没有及时观看电视，则需要多等几天再看电视才可以获取电话号码
:::

## 道具

:::note
除啤酒是**无限供应**之外，其他道具均为**有限使用**

部分道具家里自带，部分道具可以通过外卖订购，部分住客在进门时贿赂或个人剧情中也会给予道具
:::

:::tip[啤酒]
由邻居带来的无限啤酒，喝后清空体力
:::

:::tip[饮料]
可以通过外卖订购（一次 `两罐`）

喝后增加 **`一格` 体力**

会使**眼睛变红**
:::

:::tip[咖啡]
可以通过外卖订购

喝后增加 **`一格` 体力槽**

会使**眼睛变红**
:::

:::tip[猫罐头]
可以通过外卖订购（一次 `两个`）

用于**喂猫**
:::

:::tip[烟]
可以通过外卖订购

恢复**所有体力**，但下一天**少一格体力**

会使**牙齿变黄**
:::

::::tip[茶]
家里自带 `一罐`，可以通过外卖订购

用于**存档**

会使**腋下长真菌**

:::note
使用游戏菜单的保存功能同样可以存档
:::
::::
