# 应急中心带人机制

`应急中心工作人员` 会在 **第四天**、**第五天**、**第八天**、**第十天** 带走人

在 **第四天**、**第五天** 均会带走 `一个` 人，**第八天**、**第十天** 则是 `两个` 人

:::tip
工作人员不会带走主角自己，当屋中没有其他人时，他会直接离开
:::

在 **第五天** 会额外给一个 **`应急中心收治函`**

若在 **第七天** 放入 `消防员`，则也会给一个 **`应急中心收治函`**

:::note
**`应急中心收治函`** 可以用来指定住客会在下一次工作人员到来时被带走（无论其身份）

但若在此期间该住客身亡或离开，**不会返还**
:::
